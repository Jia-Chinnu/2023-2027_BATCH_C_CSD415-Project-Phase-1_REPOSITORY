# ⚡ TrustCharge

### AI-Based Centralized EV Charging Reliability and Smart Reservation Platform

TrustCharge is a centralized platform designed to unify fragmented Electric Vehicle (EV) charging networks into a single, seamless ecosystem. By integrating multiple charging providers, the platform aims to reduce range anxiety, assess charger reliability, estimate queue waiting times, and provide a unified reservation and wallet experience.

## 📚 Base Research Paper

**Title:** Long Trip Charging Planning of Battery Electric Vehicle Considering Vehicle Waiting Time Forecast at Fast Charging Stations: A Mixed-Integer Dynamic Programming Approach

**Authors:** Pradeep Krishna Bhat, Zhouquan Wu, and Bo Chen

**Published in:** IEEE Access, Volume 13, 2025

- 📄 [**Read the Base Research Paper (IEEE Xplore PDF)**](https://ieeexplore.ieee.org/stamp/stamp.jsp?tp=&arnumber=10933962)


This research explores long-distance electric vehicle charging plans while accounting for forecast waiting times at fast-charging stations. It uses mixed-integer dynamic programming to optimize charging decisions and reduce total journey time.

## 🚀 Key Features

- **Centralized Hub:** Integrates charging information from multiple providers into one application.
- **AI Reliability Score and Charger Health:** Helps users assess charging station reliability before arrival.
- **AI Queue Prediction:** Estimates waiting times using available historical and real-time data.
- **Cross-Network Reservation:** Supports advance charging-slot reservations where providers allow them.
- **Unified Wallet:** Provides a centralized membership and payment experience.
- **Real-Time Navigation and Routing:** Helps users find suitable charging stations based on location and battery status.
