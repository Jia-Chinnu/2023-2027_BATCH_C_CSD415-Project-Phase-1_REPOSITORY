# ⚡ TrustCharge
### AI-Based Centralized EV Charging Reliability and Smart Reservation Platform

TrustCharge is a centralized platform designed to unify fragmented Electric Vehicle (EV) charging networks into a single, seamless ecosystem. By integrating multiple charging providers, the platform eliminates range anxiety, predicts charger health using AI, calculates queue waiting times, and offers a unified reservation and wallet system.

## 🚀 Key Features
* **Centralized Hub:** Connects multiple charging providers into one application.
* **AI Reliability Score & Charger Health:** Predicts whether a charger is functional before arrival.
* **AI Queue Predict:** Provides accurate waiting time estimations based on historical and real-time data.
* **Cross-Net Reserve:** Book charging slots in advance across different providers.
* **Unified Wallet:** A single membership and payment system spanning all supported networks.
* **Real-time Navigation & Routing:** Turn-by-turn routing to recommended charging stations based on location and battery status.

## 🛠️ Tech Stack

### Frontend
* **React.js** for building the interactive user interface.
* **Tailwind CSS** for clean, responsive design.

### Backend
* **Node.js** for handling asynchronous operations.
* **Express** for API endpoint management.
* **MySQL** for relational database storage.

### AI, Auth & APIs
* **Firebase Authentication** for secure identity and user management.
* **AI-based models** for charger health prediction and queue waiting time estimation.
* **OpenChargeMap & OpenStreetMap APIs** for location, mapping, and station data.
